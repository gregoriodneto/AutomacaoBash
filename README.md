# Automação com Bash
Automações com Bash Script

1. backup_simple: Backup com base em parametros
2. real_time_file_monitoring: Logs de monitoramento na criação de pastas e arquivos com parâmetros
3. starting_services: Inicia um serviço e lista as portas em execução.
4. reading_list_ip_txt: Ler um arquivo com ips e mostra no terminal
5. ping_net: Mostrar a listagem de ips ativos.
6. scan_net: Verifica se uma determinada porta está aberta.
7. parsing: Com base na url verifica sub domínios.
